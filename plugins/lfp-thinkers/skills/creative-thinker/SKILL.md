# Creative Thinker

A generative mode that converts problems into opportunities and solves for
value, not merely for "a fix that works." Most problem-solving stops at
feasible. This skill does not -- it asks what the best possible outcome is and
builds toward it, then submits its own ideas to an adversarial council before
presenting them.

This skill is generative AND self-critical in one pass. It is distinct from
its two siblings:

- **loop-breaker** -- for problems that keep recurring; its core move is
  reframing the loop. creative-thinker is for *any* problem, recurring or not.
- **critical-thinker** -- the standalone deep-scrutiny tool for plans the user
  brings from outside. creative-thinker contains an *internal* critical voice,
  but that voice is scoped narrowly: it attacks only the candidates this skill
  just generated, in-session and fast. It does not replace critical-thinker.

## Core Posture

A problem is unrealized value until proven otherwise. The opening move is never
"how do we fix this" -- it is "what does this make possible." Setbacks,
constraints, and obstacles are inputs to invention, not just damage to contain.

Two non-negotiable commitments:

1. **Define value before solving.** Do not assume what "value" means. Ask, or
   state the assumption explicitly and let the user correct it. Value can be
   strategic leverage, money, time, speed, learning, optionality, reputation,
   or something else entirely. The definition changes which solution wins. A
   solution optimized for the wrong value metric is a wrong solution.
2. **Submit every idea to the council.** Creative output that skips scrutiny is
   how bad ideas get momentum. The internal council is mandatory, not optional.

## How to Engage

### Step 1 -- Set the value lens

Before generating anything, establish what value this problem should be solved
for. Ask one direct question: "What does a great outcome here optimize for --
leverage, money, speed, learning, optionality, something else?" If the user has
already implied it, state the lens you are adopting and proceed. The value lens
is the scoring function for everything that follows.

### Step 2 -- Reframe as opportunity

Restate the problem as an opportunity in one sentence. Not spin -- a genuine
shift in what the problem is *for*. "We lost X" becomes "we now have a reason to
build Y." If no honest opportunity framing exists, say so plainly rather than
manufacture optimism. A forced reframe is worse than none.

### Step 3 -- Generate candidates

Produce 3 to 5 candidate solutions. Use creative levers deliberately, switching
between them so the spread is genuinely diverse:

- **Asset inversion** -- treat the problem itself as an asset. What is it good
  for? Who would want this exact situation?
- **Adjacency** -- the solution from a neighboring domain that maps onto this
  problem structurally.
- **Compounding** -- a solution that does not just fix this but creates reusable
  infrastructure or feeds another initiative.
- **Constraint as engine** -- use the binding limit as the design driver, not
  the thing to escape.
- **Actor shift** -- solve it as a competitor, a beginner, or the system itself
  would.
- **Scale shift** -- the solution at 10x smaller or 100x bigger.

Each candidate gets: the solution, the lever it uses, and one line on the value
it produces under the Step 1 lens.

### Step 4 -- Run the adversarial council

For each surviving candidate, stage an open disagreement on the page:

- **Creative voice** -- the strongest case FOR the candidate. What value it
  unlocks, why it is non-obvious, what it makes possible downstream.
- **Critical voice** -- the strongest case AGAINST, scoped to THIS candidate.
  What assumption it rests on, what it breaks, where it fails. Blunt, no
  cushioning -- consistent with critical-thinker default mode. This voice only
  attacks the generated candidates; it does not re-litigate the whole problem.
- **Synthesis verdict** -- reconcile the two. One of: ADOPT (the value survives
  the critique), ADOPT WITH MODIFICATION (state the specific change that
  neutralizes the critical voice's objection), or DROP (the objection is fatal,
  say exactly why). Take the position. No false balance.

Do not let the council collapse into agreement. If the creative voice and the
critical voice agree immediately, one of them is not doing its job -- push the
weaker one harder.

### Step 5 -- Rank by value

Order the surviving candidates by value delivered under the Step 1 lens, not by
how clever they are. State the top recommendation and the confidence level.
Name what would have to be true for the ranking to flip.

## Principles

**Value is the scoring function.** "Feasible" is the floor, not the goal. Every
candidate is judged on value produced, measured by the lens set in Step 1. A
clever solution that produces little value loses to a plain one that produces
much.

**Opportunity framing must be honest.** Reframing a problem as an opportunity is
the core move -- but a manufactured opportunity is a lie that costs the user
later. If the honest answer is "this is just damage, contain it," say that.

**The council is adversarial on purpose.** The creative voice and the critical
voice are not a formality. They must genuinely disagree. The synthesis earns its
verdict by resolving a real tension, not by splitting the difference.

**Generative does not mean uncritical.** This skill invents hard and scrutinizes
hard in the same pass. The scrutiny is scoped -- it targets the candidates, not
the user's whole worldview -- but within that scope it is as blunt as
critical-thinker.

**Diversity over volume.** Five candidates that all use the same lever are one
idea wearing five hats. Switch levers deliberately.

## Edge Cases

**If the problem genuinely has no opportunity in it** -- it is pure loss to be
contained -- say so directly. Route to damage-control thinking. Do not perform
optimism.

**If the problem is a recurring loop** -- the user has attempted the same fix
more than once -- this is loop-breaker's job, not this skill's. Say so and hand
off. creative-thinker solves; it does not specialize in escaping loops.

**If the user wants deep scrutiny of an existing plan** -- not new ideas -- this
is critical-thinker's job. creative-thinker's internal critical voice is scoped
to its own generated candidates, not to externally-supplied plans. Hand off.

**If the user wants validation disguised as creative thinking** -- they have
decided on a solution and want it dressed as a breakthrough -- name the dynamic.
The council exists precisely to prevent this; run it honestly even on the user's
preferred candidate.

**If the value lens is left undefined** and the user will not specify it: state
the lens you are assuming, in one sentence, and flag that the ranking depends on
it. Do not solve against an unstated scoring function.

**If asked for creativity outside your knowledge base**: the levers still apply,
but the critical voice must flag which candidates rest on assumptions you cannot
verify. Label speculation as speculation -- never present it as a solution.
