# Calibracion de Audiencia Ejecutiva

Este archivo aplica cuando el destinatario del correo convertido es un ejecutivo (C-Suite,
Gerente General, Gerente de Flota, CFO, o equivalente)  -  el caso por defecto para VMC
Subastas / Echo Chamber, y probablemente el caso mas comun de uso de este skill en general.

## La calibracion correcta: menos tiempo, no mas formalidad
El error mas comun al escribir "para un ejecutivo" es asumir que eso significa mas
formalidad, mas cortesia, mas preambulo. Es exactamente al reves: un ejecutivo tiene MENOS
tiempo, no mas tolerancia a la formalidad. La formalidad corporativa plana ("Espero que este
correo le encuentre bien", "Sin otro particular, quedo atento") es precisamente lo que el
metodo Patel reemplaza  -  no lo que hay que anadir para sonar "apropiado" a un cargo alto.

## Reglas concretas
- **Conserva toda especificidad y cifras del original.** Un ejecutivo no descarta un correo
	por ser especifico  -  lo descarta por ser vago. Si el borrador original tiene una cifra,
	un plazo, un numero de unidades, conservalo exacto. Nunca lo generalices para "sonar mas
	pulido".
- **Corta los aperturas de cortesia.** "Espero que se encuentre bien", "Mi nombre es X y me
	contacto de parte de Y", "Queria tomarme un momento para..."  -  todo esto se elimina sin
	excepcion. Un ejecutivo lee en skim; lo primero que salta es exactamente esto.
- **120-150 palabras maximo por correo**, salvo que el patron C (urgencia de cierre) o una
	instruccion explicita del usuario pida algo distinto. Si el borrador original es mas
	largo, la conversion casi siempre incluye recorte, no solo reestructuracion.
- **Un solo CTA, de bajo compromiso, por correo.** Nunca pidas dos cosas ("respondeme y
	agenda una llamada")  -  un ejecutivo responde a UNA pregunta clara, no a un menu de
	opciones. La friccion del CTA debe ser la minima necesaria para el objetivo del touch
	(ver la regla de curva de friccion en `patterns.md`).
- **Nombra el rol, no el titulo generico.** "Gerente de Flota", "CFO", "Gerente General" en
	el cuerpo del correo (cuando aplique) es mas creible que un "usted" generico  -  muestra que
	el mensaje fue pensado para ese cargo especifico, no copiado y pegado.
- **Evita el superlativo de venta.** "La mejor solucion del mercado", "revolucionario",
	"unico en su tipo"  -  un ejecutivo experimentado descuenta automaticamente cualquier
	superlativo no verificable. Prefiere el hecho concreto sobre el adjetivo.

## Guia especifica de dominio  -  VMC Subastas
Cuando el correo es para el contexto VMC Subastas especificamente:
- El mecanismo comercial ("vendes hoy, entregas hasta 180 dias despues, hasta que llegue el
	reemplazo") es el gancho mas fuerte disponible  -  no lo diluyas parafraseandolo distinto en
	cada correo si el original ya lo dice bien.
- Las cifras limpias para usar libremente: 33,397 compradores verificados, 40K+ subastas,
	20+ anos operando. NUNCA uses cifras no verificadas o rechazadas (ver lista de cifras
	baneadas en el proyecto Digital Edge / Biblia de Voz)  -  si el borrador original trae una
	cifra que no reconoces como parte del set limpio, pregunta antes de mantenerla.
- El servicio es siempre gratis para el vendedor  -  es una politica permanente confirmada,
	no una promocion temporal. Frasealo naturalmente ("sin costo para ti", "gratis"), nunca
	como oferta con fecha de vencimiento.
- Prueba social siempre a nivel de categoria ("empresas de flota", "operadores mineros"),
	nunca nombrando un vendedor real especifico sin su autorizacion explicita.
