# Los 9 Patrones  -  Anatomia y Esqueletos

Nota de origen: estos 9 patrones se derivaron de auditar 212 correos reales de Neil Patel /
NP Digital. El objetivo del skill es transferir la ESTRUCTURA retorica, nunca copiar una
linea del texto original  -  cada esqueleto de abajo usa placeholders, no ejemplos reales de
Patel.

## A  -  Pregunta Incomoda
**Cuando usarlo:** presentar una idea/propuesta y generar interes genuino, sin vender nada
todavia. Es el patron por defecto para abrir una secuencia de prospeccion fria.
**Anatomia:**
1. Gancho de contraste: "la mayoria de [audiencia] asume X  -  no es asi"
2. Una frase que nombra la tension real detras de esa suposicion equivocada
3. Una pregunta directa que el lector no puede responder sin pensar
4. Cierre de baja friccion: una pregunta simple, no una peticion de tiempo
**Esqueleto:**
```
ASUNTO: [pregunta corta que ya insinua la tension]

{{first_name}}, la mayoria de [audiencia] asume que [creencia comun]  -  no es asi.

[1-2 frases nombrando la tension real / el costo oculto de esa creencia]

[pregunta directa que fuerza a evaluar su propia situacion]?

[cierre de baja friccion  -  pregunta simple, no ask de tiempo]
```
**Formulas de asunto:** "[supuesto comun], o no?"  "lo que [audiencia] no ve de [tema]" 
"y si [supuesto] esta mal?"

## B  -  Invitacion a Webinar/Reunion
**Cuando usarlo:** invitar a una reunion, demo o evento  -  cuando el objetivo explicito es
agendar tiempo, no solo generar interes.
**Anatomia:**
1. Contexto de por que esto importa ahora (sin urgencia falsa)
2. Que se cubre / que se resuelve en esa reunion  -  especifico, no generico
3. Para quien es (calificacion implicita  -  filtra a quien no aplica)
4. CTA de agendar, con friccion minima (un rango de tiempo, no una fecha exacta forzada)
**Esqueleto:**
```
ASUNTO: [lo que se resuelve en la llamada, no "invitacion a reunion"]

{{first_name}}, [1 frase de contexto de por que esto es relevante para su situacion].

En [X minutos] cubrimos: [punto concreto 1], [punto concreto 2].

Esto aplica si [calificador implicito de audiencia].

[pregunta de agendar con rango flexible, no fecha fija]?
```

## C  -  Urgencia de Cierre
**Cuando usarlo:** SOLO cuando existe una fecha limite real (no urgencia artificial). Es el
unico patron donde el saludo formal con nombre al inicio es apropiado.
**Anatomia:**
1. Saludo directo con nombre
2. La fecha limite real, explicita, con la consecuencia concreta de no actuar
3. Recordatorio breve de la oferta/propuesta (sin repetir todo el contexto)
4. CTA de mayor friccion es aceptable aqui (es el unico patron que lo permite)
**Esqueleto:**
```
ASUNTO: [fecha/plazo explicito] + [que se pierde]

{{first_name}},

[fecha limite real] se cierra [lo que se cierra]. Despues de esa fecha, [consecuencia
concreta y real, no inventada].

[1 frase recordando la oferta, sin repetir todo]

[CTA  -  aqui si puede ser una peticion de tiempo/llamada]
```

## D  -  Historia de Origen / Relanzamiento
**Cuando usarlo:** anunciar un hito, cambio de producto, o relanzamiento  -  el gancho es
narrativo, no transaccional.
**Anatomia:**
1. Un momento concreto (no abstracto) que marco el cambio
2. Que se aprendio / que cambio como resultado
3. Como eso se traduce en algo distinto para el lector hoy
4. CTA de bajo compromiso  -  probar, ver, no comprometerse
**Esqueleto:**
```
ASUNTO: [algo cambio] + [gancho de curiosidad, no venta]

{{first_name}}, [momento concreto que marco el cambio  -  especifico, no generico].

[que se aprendio / que se rediseno como resultado]

Hoy eso significa [beneficio concreto y distinto para el lector].

[CTA de bajo compromiso  -  probar/ver, no comprar]?
```

## E  -  Cambio de Paradigma
**Cuando usarlo:** comentar una novedad real del sector para abrir conversacion  -  no vender
directamente, generar una reaccion.
**Anatomia:**
1. Un hecho/cambio real y verificable del sector
2. Por que eso cambia las reglas para [audiencia especifica]
3. Una implicacion concreta, no abstracta
4. Pregunta abierta que invita a opinar, no a comprar
**Esqueleto:**
```
ASUNTO: [el cambio de sector, nombrado directo]

{{first_name}}, [hecho/cambio real y verificable, con fuente si aplica].

Para [audiencia especifica], eso cambia [que exactamente cambia].

[1 frase de implicacion concreta para su situacion]

[pregunta abierta  -  que piensa, como lo esta viendo]?
```

## F  -  Regalo con Mecanica Clara
**Cuando usarlo:** anunciar una oferta o promocion concreta  -  el mecanismo tiene que ser
real y verificable, nunca inventado para sonar mejor.
**Anatomia:**
1. La oferta, nombrada directo, sin rodeos
2. La mecanica exacta  -  como funciona, en 1-2 frases, sin letra chica escondida
3. Por que existe esta oferta ahora (contexto real, no urgencia artificial)
4. CTA directo a reclamar/usar la oferta
**Esqueleto:**
```
ASUNTO: [la oferta, nombrada directo]

{{first_name}}, [la oferta en 1 frase clara].

Funciona asi: [mecanica exacta, 1-2 frases, sin condiciones ocultas].

[1 frase de contexto real de por que existe esto ahora]

[CTA directo  -  reclamar, empezar, usar]?
```

## G  -  Prueba con Caso y Estadistica
**Cuando usarlo:** cuando hay un resultado real y verificable que mostrar como prueba  - 
nunca una cifra inventada o no verificada.
**Anatomia:**
1. El resultado concreto primero (la cifra, el hecho)  -  no el preambulo
2. Contexto minimo de como se logro (sin caso de estudio completo)
3. Por que eso es relevante para la situacion especifica del lector
4. CTA que ofrece replicar o explorar ese resultado
**Esqueleto:**
```
ASUNTO: [la cifra o resultado, directo]

{{first_name}}, [el resultado concreto  -  cifra real, verificada].

[1-2 frases de como se logro, sin caso de estudio completo]

Para [situacion del lector], eso significa [implicacion concreta].

[CTA  -  quieres ver como aplicaria a tu caso]?
```

## H  -  Resumen Mensual de Industria
**Cuando usarlo:** seguimiento periodico sin vender directo  -  mantener la relacion viva sin
pedir nada cada vez.
**Anatomia:**
1. 2-3 puntos reales y breves de lo que esta pasando en el sector
2. Sin preambulo de "aqui esta tu resumen mensual"  -  directo a los puntos
3. Un cierre de baja friccion, opcional  -  no forzar CTA si no aplica
**Esqueleto:**
```
ASUNTO: [1-2 temas del mes, directo]

{{first_name}}, esto es lo que vimos moverse este mes:

 -  [punto 1, 1 frase]
 -  [punto 2, 1 frase]
 -  [punto 3, 1 frase, opcional]

[cierre opcional de baja friccion, o ninguno]
```

## I  -  Manejo de Objecion Social / Reactivacion
**Cuando usarlo:** reactivar un lead frio o cliente inactivo sin urgencia falsa  -  el lector
ya conoce la propuesta, no hay que reintroducir todo desde cero.
**Anatomia:**
1. Reconocimiento directo de que ya hubo contacto/relacion previa (sin exceso de disculpa)
2. Que cambio desde entonces  -  concreto, no vago ("mejoramos" sin decir que es una alerta)
3. Por que vale la pena una segunda mirada ahora
4. CTA de reconexion, baja friccion  -  nunca mayor friccion que el primer touch de la
	secuencia original
**Esqueleto:**
```
ASUNTO: [algo cambio] + [gancho de reconexion, sin urgencia falsa]

{{first_name}}, [reconocimiento directo de la relacion/contacto previo  -  sin exceso de
disculpa].

[que cambio concretamente desde entonces  -  especifico, verificable, nunca vago]

[1 frase de por que vale la pena mirar de nuevo]

[CTA de reconexion  -  baja friccion, igual o menor que el touch 1 original]?
```

## Arco de cadencia (para secuencias multi-touch)
Cuando conviertas una secuencia completa (no un correo suelto), el arco correcto entre
touches es: educa  refuerza con prueba  maneja objecion especifica  cierra con
retirada/oferta de bajo compromiso, del touch mas largo (educar necesita mas espacio) al
mas corto (el cierre es siempre el mas breve). La friccion del CTA debe bajar o mantenerse
constante touch a touch  -  nunca subir (ej. de "dime cuanto tienes" a "hablemos 15 minutos"
es una regresion, no una progresion).
